# ADRs

Architecture Decision Records capture durable Pay4 product, commercial, UX, and technical decisions that should be easy to find later.

Use ADRs when a decision:

- Changes the product model or shared language.
- Affects customer, merchant, issuer, or Pine Labs operating behavior.
- Will influence PRD, GTM, support, settlement, compliance, or implementation.
- Needs context and consequences, not just a bullet in `CONTEXT.md`.

Use `CONTEXT.md` for the living domain model and lightweight decision log. Create or update an ADR when a decision becomes durable.
